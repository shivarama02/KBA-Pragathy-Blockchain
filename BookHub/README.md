# BookHub

BookHub is a simple library management system UI created as part of the KBA HTML and Tailwind CSS workshop.

It provides a clean interface for:

- Signing up as a librarian or member
- Logging in to the application
- Viewing the available books
- Adding a new book
- Editing book details
- Viewing the playful forgot-password message


## Project Structure

```text
BookHub/
├── Addbooks.html       # Add a new book
├── Viewbooks.html      # Browse available books
├── editbooks.html      # Edit book details
├── home.html           # BookHub dashboard
├── login.html          # Login page
├── signup.html         # Registration page
└── images/             # Book covers and BookHub logo
```

## Getting Started

No installation or build step is required.

1. Open the `BookHub` folder.
2. Open `login.html` in a web browser.
3. Use the navigation links to explore the application.


Then open [http://localhost:8000/login.html](http://localhost:8000/login.html).

## Important Note

This is currently a frontend workshop project. Login, signup, add, edit, and delete actions are represented by static page navigation and forms. There is no backend, database, authentication, or persistent book storage yet.

## Technologies

- HTML5
- Tailwind CSS via CDN
